# README 面向读者重写实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将项目自有 README 统一改写为面向公开读者的结构说明和使用指南，同时保留有学习价值的技术原理。

**Architecture:** 以项目主链路为组织方式：根 README 负责总览和快速开始，`data/` README 负责数据流与数据入口，`sqlite_agent/scripts/` README 负责可执行脚本入口。内部迁移、删除和清理记录从 README 中移除，技术演进仍由根 README 链接到专题文档。

**Tech Stack:** Markdown、Python CLI、Bash、Git、`rg`。

## Global Constraints

- README 面向公开用户，不承担内部交接、迁移日志或仓库整修记录。
- 每个主要目录必须说明用途、当前文件、推荐入口、输入输出和重要约束。
- 至少给出一个可复制命令，或明确链接到包含完整命令的上级指南。
- 保留 XML、repair、协议训练和 Teacher rollout 等具有学习价值的技术演进。
- 所有路径和命令必须指向当前仓库中真实存在的文件。
- 不修改 `docs/` 中有学习价值的技术复盘正文。
